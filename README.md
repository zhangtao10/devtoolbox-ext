# DevToolbox 开发者工具箱（Chrome 插件）

纯原生 JS、Manifest V3，无构建步骤，所有处理均在本地完成，不发起任何网络请求。

| 功能 | 说明 |
| --- | --- |
| JSON 解析 | 格式化 / 压缩 / 键排序 / 转义 / 去转义，树形视图（折叠、点击显示 JSONPath、双击复制值），错误精确到行列；宽松模式支持注释、尾逗号、单引号、无引号键；粘贴 curl 命令可直接发送请求并解析返回数据 |
| JSON 对比 | 语义级 diff（新增 / 删除 / 修改 + JSONPath），左右对照高亮，可只显示差异行，可忽略键顺序 |
| 颜色转换 | HEX / RGB(A) / HSL(A) / HSV / HWB / CMYK / OKLCH / 整数 / Android ARGB / UIColor / CSS 颜色名互转，透明度，WCAG 对比度，色阶 |
| 页面取色 | 弹窗点「页面取色」→ 页面右上角出现取色浮层（EyeDropper API），结果自动复制并存入取色历史；受限页面自动退回到工具页屏幕取色 |
| 时间戳 | 秒 / 毫秒 / 微秒 / 纳秒自动识别，日期 → 时间戳，任意时区，实时时钟 |
| 编码解码 | Base64 / Base64URL / URL / URI / Unicode / HTML 实体 / Hex；MD5、SHA-1/256/384/512；JWT 解析（含过期检查） |
| 正则测试 | 实时高亮、分组 / 命名分组、替换预览、6 个 flag、15 个常用正则预设 |

## 大数据处理

- 解析、格式化、diff 均在 Web Worker 中完成，不阻塞页面；新输入会中止仍在进行的旧计算
- JSON 树惰性渲染：只在展开时创建子节点，大数组每批显示 200 项；“全部展开”最多渲染 20,000 个节点
- 逐行对照使用线性空间 Myers 算法（O((N+M)·D) 时间、O(N+M) 内存），超出计算预算时退化为整块替换并提示“近似结果”
- 对照视图虚拟滚动，只渲染可视区域的行；差异列表最多显示 1,000 条
- 超过 512 KB 的输入不写入本地缓存

实测（Chrome）：16 MB / 180 万节点 JSON 约 1 秒可交互；50,000 个对象（约 27 万行）对比不到 1 秒。

## 安装

1. 打开 `chrome://extensions`，右上角开启「开发者模式」
2. 点击「加载已解压的扩展程序」，选择本目录
3. 点击工具栏图标（或 `Alt+Shift+J`）打开

## 开发

```bash
npm test                   # 运行 lib/ 下核心逻辑的单元测试（node --test，无依赖）
node scripts/gen-icons.js  # 重新生成图标
```

```
manifest.json   插件清单
popup.*         工具栏弹窗
picker.js       注入网页的取色浮层
app.*           工具主页面（hash 路由）
tools/          各工具的 UI 逻辑
lib/            纯逻辑模块（可在 Node 中测试）
test/           单元测试
```
